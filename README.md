# E-Commerce Data Analysis using SQL

## 📌 Project Overview
This project focuses on analyzing an e-commerce dataset using SQL to understand customer behavior, sales trends, and regional performance.  
The analysis was performed using Google BigQuery and focuses on deriving actionable business insights.

---

## 📌 Objective
- Analyze order and payment data to identify trends and patterns
- Understand customer distribution across regions
- Perform time-based analysis such as month-on-month growth
- Provide data-driven insights and recommendations

---

## 📌 Dataset Description
- Public e-commerce dataset
- Tables used:
  - customers
  - orders
  - payments
- Data includes customer locations, order timestamps, and payment values

---

## 📌 Tools & Technologies
- SQL (Google BigQuery)
- Joins, CTEs, Window Functions
- Aggregations and Time-based Analysis

---

## 📌 Key Analyses Performed
- Month-on-month order analysis
- State-wise customer distribution
- Revenue and average order value analysis by state
- Payment trend analysis
- Customer activity analysis

---

## 📌 Key Insights

### 🔹 Revenue Concentration
A significant portion of total revenue is generated from a small number of states, indicating high regional concentration.

**Recommendation:**  
Diversify growth by targeting underperforming but high-potential states through marketing and logistics improvements.

---

### 🔹 Seasonal Order Trends
Order volumes show noticeable spikes during specific months, suggesting seasonal buying behavior.

**Recommendation:**  
Prepare inventory and delivery capacity in advance for peak periods.

---

### 🔹 Regional Differences in Order Value
Certain regions show higher average order values compared to others.

**Recommendation:**  
Adopt region-specific pricing or promotional strategies.

---

## 📌 Limitations
- Customer demographics data is not available
- Churn analysis is based only on order inactivity
- Marketing spend data is not included

---

## 📌 Conclusion
This analysis demonstrates how SQL can be used to transform raw transactional data into meaningful business insights that support strategic decision-making.
